# Introduction to Java<br>and CSS playground

---

## Java Basics

* Java is an object-oriented programming language.
* All code has to belong to a class
* Entrypoint is usually the *main* method in **Main** class

---

## (Naming) conventions

* class names start with upper case letters
* method and variable names start with lower case letters
* use camelCase rather than snake_case
* each class is in its own file
* filename is Classname.java
* There are no header files like e.g. in C++

---

## Fun Facts

* Java was developed by Sun Microsystems in 1995
* It's creator was James Gosling (no known relation to Ryan)
* Alternavtive names under discussion were: Oak, Silk, DNA
* Java is related to Java Coffee, but it's not clear who came up with the name
